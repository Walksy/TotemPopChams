<h1>Totem Pop Chams!</h1>

This mod captures the visual state of a player when they pop a totem of undying and displays a 'ghosted' version in that place.

---

**Information**

_**Disperse Settings**_

![Disperse](https://cdn.modrinth.com/data/cached_images/85ceeaa0b0243861b073e8181f0d2a7f5f4c9d28.gif)

*(Low FPS due to gif)*


- These settings make the model fly outwards from the player's pop position, instead of it staying in the same place. 
- You can control the distance (in blocks) it travels and the speed it travels at.
- These settings still factor in the lifetime of the ghost, so you may have to tweak the lifetime if you want a larger coverage.
